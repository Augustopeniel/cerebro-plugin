# cerebro-plugin

Marketplace do plugin `cerebro`, que conecta o Claude ao seu cérebro no Cérebro Vivo (https://cerebro.ogidoc.com). Este repositório tem só o plugin, sem nenhum segredo: o login é feito pelo próprio Claude (OAuth), com a sua conta do portal.

```
/plugin install cerebro --marketplace Augustopeniel/cerebro-plugin
```

Detalhes em [`cerebro/README.md`](cerebro/README.md). O código do servidor não fica aqui; este repositório é gerado a partir dele a cada versão.
